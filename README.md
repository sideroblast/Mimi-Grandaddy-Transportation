# Mimi & Grandaddy Transportation

Mobile-first family transportation scheduler using GitHub Pages + Supabase.

Features: combined Mimi/Grandaddy schedule, distinct colors, Needs Driver, I Can Drive, My Rides, add/edit/delete events, real-time updates, passwordless email login, calendar export, and responsive phone/desktop layout.

## Configuration
Paste your Supabase Project URL and browser-safe publishable key into `config.js`.
Never put a `service_role` key in browser code or GitHub.

Run `supabase-schema.sql` once in the Supabase SQL Editor, then add family email addresses to `family_members`.
